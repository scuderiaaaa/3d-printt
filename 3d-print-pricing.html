Set up Google Sheets (one time)
  1. Open your Google Sheet. Go to Extensions > Apps Script.
  2. Delete what is there, paste the code below, then click Save.
  3. Click Deploy > New deployment. Choose type Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and approve the permissions.
  4. Copy the Web app URL and paste it here:
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName('Print Jobs') || ss.insertSheet('Print Jobs');
  if (sh.getLastRow() === 0) {
    sh.appendRow(['Date', 'Program', 'Project name', 'Grams', 'Price']);
    sh.getRange(1, 1, 1, 5).setFontWeight('bold');
    sh.setFrozenRows(1);
  }
  data.rows.forEach(function (r) {
    sh.appendRow([r.date, r.program, r.project, r.grams, r.price]);
  });
  return ContentService.createTextOutput('ok');
}

After this, one click on “Send to Google Sheets” adds every job not yet sent as new rows. If you change the code later, create a new deployment version.
